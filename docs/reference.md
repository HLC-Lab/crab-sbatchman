# Reference

This page lists every file of the repo, the options of `install.sh`, and which files you may change.

| Path | What it holds |
|---|---|
| `install.sh` | The installer. |
| `benchmarks/` | The shipped benchmarks and their jobs files. |
| `docs/` | The documentation pages. |
| `configs/` | The Slurm configuration file for the cluster. |
| `site/` | The per-site settings file. |
| `CRAB/` | The CRAB submodule. |
| `crab-wrappers/` | The wrappers submodule. |
